# Logos

- `kriativa-logo.svg`: the full lockup, K symbol plus "kriativa" wordmark, single ink **#ffffff** on a transparent 800×800 artboard (the mark sits in the middle band, so crop or offset it when placing). Use on `bg` and other dark grounds. This is the file the site's nav and footer use.
- `k-symbol-white.png`: the K symbol alone in white, for avatars, favicons and small spaces on dark grounds.
- `k-symbol-black.png`: the K symbol alone in black, for light grounds only.
- `kriativa-icon.png`: the app/social icon.

Keep 1x clear space on every side (1x = half the K symbol's height). Never distort, rotate, fade, recolour or add effects, and never place the logo on a coloured ground.
