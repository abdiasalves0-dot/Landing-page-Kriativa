# Icons

The six service icons from the landing page's services grid. Each is a 28×28 SVG drawn with 1.5px strokes in a single ink, **#f2f0eb** (`white`), no fill, so they only work on dark grounds. Show them at 70% opacity above the service name.

| File | Service |
| --- | --- |
| `identidade-visual.svg` | Identidade Visual: two squares and two discs |
| `web-design.svg` | Web Design: a monitor |
| `software-and-web.svg` | Software & Web: a globe |
| `ui-and-ux-design.svg` | UI & UX Design: a sun, a circle with eight rays |
| `motion-design.svg` | Motion Design: three stepped lines |
| `estrategia-de-marca.svg` | Estratégia de Marca: an isometric cube |

Draw new icons the same way: a 28px box, 2px inset, 1.5px stroke, round caps or joins, built from simple geometric primitives.
