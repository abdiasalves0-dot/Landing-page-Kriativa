# SectionHeading

The brand's signature heading: a bracketed eyebrow, an uppercase Inter Black line and an italic Playfair line beneath it, plus the ruled section header with a count.

- Eyebrow `.eyebrow`: `eyebrow` style in `muted`, wrapped in `[ ]`, 24px above the headline.
- Headline `.headline` (`heading-section`) with `.headline-em` (`serif-section`, `white-dim`, on its own line). In the hero use `display-hero` with `serif-hero` in the same pairing.
- Section header `.section-header`: a hairline rule on top, `space-40` padding, `.section-title` left and `.section-count` (e.g. "06 especialidades") right, aligned to the bottom.
- The consumer provides both halves of the headline: the first half states, the italic half completes it.
