# ServiceCard

A square cell in the services grid: number, line icon, uppercase name and a light description; on hover it tints to `bg2` and draws a 2px cream underline from the left.

- Always place cards inside `.services-grid` (3 columns, 1 column under 900px): the 1px gap over `white-border` draws the hairlines.
- Padding 40px/36px. Number `index-number` in `muted`; icon 28px at 70% opacity (from the Icons group); name `heading-service`; description `body` in `muted`.
- The consumer provides the two-digit number, the icon, the name and a one-sentence description.
