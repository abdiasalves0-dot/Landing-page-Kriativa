# Nav

The fixed top bar: logo left, uppercase links, nav CTA far right, over a gradient that fades from `bg` at 95% to transparent.

- Padding 28px / `space-60` on desktop; 16px / `space-24` under 900px, where `.nav-links` are hidden and only logo and CTA remain.
- Links use the `nav-link` style in `white-dim`, `white` on hover, 40px apart.
- The consumer provides the logo (`kriativa-logo.svg`), the links (anchors to page sections) and the CTA target.
