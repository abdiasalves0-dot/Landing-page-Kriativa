# Footer

The closing block: a brand column with logo and tagline, link columns, and a bottom row with copyright and sign-off.

- Columns are 1.5fr then 1fr each (the site uses four: brand, Serviços, Estúdio, Contato); 2 columns under 900px.
- Column titles are 11px weight 500 uppercase in `white`; links use `body` in `muted`, `white` on hover; the copyright uses `caption`.
- The consumer provides the columns and links; keep the sign-off "Feito com intenção.".
