# WorkCard

A portfolio tile: a full-bleed image in a 4:3 frame with the category and project name on a gradient at the bottom.

- Lives in a 2-column grid with a 2px gap over `white-border`; the first card spans both columns at 16:7.
- On hover the image scales to 1.04 and the caption rises 8px.
- The tag uses `index-number` tracking in `muted`; the name uses `heading-card`.
- The consumer provides the image (`bg3` shows until it loads), the category and the project name.
