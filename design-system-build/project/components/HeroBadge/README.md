# HeroBadge

A floating glass card with one figure and a label, marked live by the pulsing green dot.

- `white-subtle` fill with a 12px backdrop blur, hairline border, `radius-lg`, 20px/24px padding.
- Figure `badge-stat`; label 12px light uppercase in `muted`, preceded by `.hero-badge-dot` in `status-live`, the only place the green appears.
- Floats at the right of the hero and is hidden under 900px. The consumer provides the figure and the label.
