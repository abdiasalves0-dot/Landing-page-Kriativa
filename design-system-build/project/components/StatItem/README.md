# StatItem

A big number with a short cream bar and an uppercase label, laid out in a hairline-divided row on `bg2`.

- `.stat-num` uses `stat-number` (Inter 900, up to 88px); `.stat-bar` is 32×2px in `accent`; `.stat-label` uses `stat-label` in `muted`.
- On the site the number counts up from 0 to its target when it scrolls into view.
- The consumer provides the number (put a unit in the label, e.g. "(%)") and the label.
